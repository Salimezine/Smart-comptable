3. Données personnelles

Smart Comptable traite les données suivantes :

  • Données comptables : écritures journal, factures, bulletins de paie, stocks — stockées localement dans le navigateur (localStorage) et, le cas échéant, sur un serveur Supabase choisi par l'utilisateur.
  • Données d'identification : nom, email, mot de passe (hashé), PIN (hashé) — stockés localement.

Aucune donnée n'est revendue, louée ou partagée avec des tiers non nécessaires au fonctionnement du service. L'utilisateur conserve la maîtrise totale de ses données et peut les exporter ou les supprimer à tout moment via la fonctionnalité de backup/restore intégrée.

4. Sécurité

  • Les données sont chiffrées AES-256 côté navigateur lorsque le verrouillage PIN est activé.
  • Les sessions utilisateur sont protégées par PIN ou email/mot de passe.
  • Les sauvegardes exportées peuvent être protégées par un mot de passe de chiffrement.
  • Aucun accès distant aux données n'est possible sans authentification préalable.

5. Cookies

Smart Comptable n'utilise pas de cookies publicitaires ou de traçage tiers. Seuls des mécanismes de stockage local (localStorage) sont utilisés pour le fonctionnement de l'application (session utilisateur, préférences d'affichage).
